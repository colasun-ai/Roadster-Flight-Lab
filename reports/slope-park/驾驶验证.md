# 坡道试验区 · 0.9.9

Tesla Garage → 开始驾驶 → 坡道试验区。在选单里看纵剖面和建议车速，点「前往起点」会把当前车辆停在入口前 41 米。也可以从原有特技跳台沿道路向前开进新区。

| 分区 | 试验车道 |
|---|---|
| A 爬坡与坡起 | 8%、15%、25%、35%、45% 的上坡、坡顶和下坡 |
| B 纵向起伏 | 长波、短波、渐强波浪、双峰夹谷、搓板路 |
| C 侧倾与交叉轴 | 左高侧坡、右高侧坡、反向扭转、交叉轴波浪、S 弯倾斜路 |
| D 飞坡与落地 | 桌面跳台、短距飞坡、双段连跳、断崖落差、长距大跳 |

坡度百分比表示每 100 米水平距离的爬升米数。剖面图按各车道高度缩放。建议车速供模拟器试驾使用。

## 实测

20 条新车道包含 25 个封闭实体。已逐一检查网格边缘闭合与朝向。渲染和 Rapier 共用坡面顶点，1788 次射线对照均在 3 毫米容差内。

Roadster、Model 3 和 Model Y 均从静止起步，以 120 Hz 物理步进完成全部 20 条车道，共 60 趟。动力、制动和转向通过车辆控制器施加。各趟的离地时间、侧倾和横向偏差见「坡道物理验证.json」。

Mac 打包应用另以 Roadster 的键盘驾驶输入走完 A5 和 D5。A5 坡顶车身参考点约 11.25 米。D5 车身参考点最高约 7.23 米，四轮离地后重新接地。既有动力、喷气、补气、场地及操控测试共 76 项通过，FSD 测试套件也通过。本次实机平台为 Apple Silicon Mac。
