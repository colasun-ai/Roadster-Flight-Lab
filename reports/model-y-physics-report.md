# 2026 Model Y Performance — v0.7 物理标定

市场统一为美国 / 北美 2026 款，来源和冲突逐项见 `model-y-performance-specs.md` 与 `model-y-performance-parameters.json`。这里记录模拟器实际工程模型，不声称取得 Tesla 私有电机图谱、减振控制器或稳定系统算法。

## 动力、制动和底盘

综合峰值设 380 kW、700 N·m，以当代美国媒体约 510 hp 测试资料和加速曲线作工程拟合。前后轴分别限 100 / 280 kW、220 / 480 N·m，综合总限额仍只计算一次。9.8:1 单速减速比、效率、前后扭矩曲线均为估计；电机扭矩经过传动和轮胎接地后才产生轮上驱动力，没有将 700 N·m 当作每轮扭矩。

前电机为感应、后为永磁同步的简化模型，具备低速恒扭矩、高速恒功率和更高速衰减。牵引控制按四轮滑移和载荷限制实际驱动力，ABS 独立限轮上制动；再生峰值 85 kW / 230 N·m，并受 SOC 和低速限制。电池 81 kWh 是工程参考值，当代媒体容量存在冲突。最高速度用 249.448 km/h 附近的驱动扭矩调节，没有设置刚体目标速度。

Chill / Standard / Insane 分别使用不同的响应和功率/扭矩限额；没有新增超过综合峰值的作弊模式。Standard / Sport 减振是基础阻尼与 1.25 倍阻尼的工程预设，不能称为完整复刻原厂主动调节策略。Normal / Reduced 稳定辅助调整 TCS/ESC 介入，无旧款 Track Mode。

前 / 后弹簧 52,000 / 56,000 N/m，阻尼 5,500 / 6,200 N·s/m。前 / 后抗侧倾刚度 32,000 / 36,000 N/m，按同轴两侧悬挂压缩差施加等量反向的实际接地载荷耦合。没有冻结高度、直接校正滚转、写入水平速度或改变 120 Hz 时间步。

轮胎 μ：干地 1.02、湿地 0.62、砂石 0.52、冰面 0.085；CdA 0.61 m²、滚阻 0.0105，均是工程近似。Model Y 使用 0.001 额外线性阻尼；此前沿用的 0.015 会在气动阻力之外重复引入明显高速损失。Roadster 和 Model 3 的默认值保持不变。

## 实际动力测试

`tests/modely.test.js`，Rapier 0.19.3、固定 120 Hz、干地 μ=1.02、90% SOC、2,101 kg、Insane、平坦长测试地面。由真实驱动力从静止加速，按刚体速度和纵向距离插值穿越阈值，无强制速度、计时偏移或固定减去 0.3 秒。

| 项目 | 严格静止 | 精确排除前 0.3048 m |
| --- | ---: | ---: |
| 0–60 mph | 3.7711 s | 3.3516 s |
| 0–100 km/h | 3.9364 s | 3.5170 s |
| 0–160 km/h | 7.9171 s | 7.4977 s |
| 0–100 mph | 7.9975 s | 7.5781 s |
| 1/4 mile | 11.9389 s | 11.5194 s |

本次实际 1 foot 排除段为 0.419409 s。四分之一英里终点瞬时速度 199.464 km/h，不是媒体使用的定长测速区平均 trap speed。90 秒最高实测 248.917 km/h。厂方 3.3 s 为扣 rollout 的宣传值；媒体测试车质量、轮胎和计时不同，因此不宣称与严格静止 3.3 s 相同或精确复刻所有实车指标。

综合实测峰值低于 380 kW / 700 N·m，前 / 后低于 100 / 280 kW；两个电机均实际出力。90 秒平地加速没有四轮同时离地，根节点垂直范围约 1.2 mm。全部 14 项动力、模式、四路面、转向、再生/ABS/TCS、坡道/碰撞/翻滚及连续切车检查通过，详见 `model-y-physics-results.json`。

100 km/h 两方向各 30% 转向持续 2 s，航向改变约 ±20.23°；200 km/h 为 ±13.52°、最大滚转约 1.45°。车辆自身限速约 249 km/h，因此没有伪造 Model Y 300 km/h 正常驾驶测试。Roadster 的 300 km/h 与喷气工况在其原套件及严格轨迹回归单独验证。

## 发现并修复的弹跳

软 SUV 悬挂在 200 km/h 转弯时触及行程限位，缺少同轴抗侧倾耦合，曾真实出现约 0.80 m 弹起和 30° 滚转。`model-y-roll-stability-bugfix.json` 对照保持同一原始 0.015 线性阻尼和输入，仅改变抗侧倾耦合：旧问题复现，修复后根节点上抬 <25 mm、滚转 <3°、向上速度 <0.1 m/s。最终正常 0.001 阻尼参数另由完整 14 项测试验证，不能把两个不同阻尼工况混为一组对照。

几何验证只覆盖离散姿态而不是连续碰撞或轮胎变形；物理模型仍是刚体和射线轮胎，不包含真实软胎、热衰减、准确电池温度和私有稳定算法。实际 Mac 帧率、切车资源与持续运行结论见本版性能/原生报告，不能由这些离线 Node 测试推断。
