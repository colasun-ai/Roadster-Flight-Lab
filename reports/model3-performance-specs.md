# 2018 Tesla Model 3 Performance：历史规格与标定依据

核验日期：2026-10-21（Asia/Shanghai）。适用对象：2018 年 Model 3 Performance Dual Motor AWD，优先对应当年的 Performance Upgrade 配置。本文件是资料与标定约束，不是模拟器实测结果；实际采用的工程参数和成绩见物理、测试报告。

| 标记 | 含义 |
| --- | --- |
| 厂方历史数据 | Tesla 在 2018 年发布的文件；历史手册镜像另外注明宿主和适用范围 |
| 同年代实测数据 | 当时媒体亲自测试的成绩，或其测试车规格表列值；规格表不等于台架测出的电机曲线 |

## 计时规则：不能把 3.3 秒当作无 rollout 门槛

C/D 于 2019-12-05 说明：此前以到达 **3 mph** 近似 rollout，2019 年 12 月期刊起改为精确 **1 ft**。2018 年原文没有公布能还原严格静止时间的 rollout 分量；今日访问的历史文章也未说明是否重算。因此历史 3.5 s 应保留为 C/D 历史口径，不能声称是严格静止，也不能强称已证实为精确 1 ft。[C/D 原始方法变更说明](https://www.caranddriver.com/features/a30085446/acceleration-testing-procedure-change-rollout/)。

2018-10-19 Electrek 向 Tesla 询问后报道：3.5→3.3 的宣传变更并非硬件或软件升级，而是与排除初始 rollout 的媒体结果保持一致。原文有一处关于 rollout 的措辞与邻近 Dragy 叙述不一致，故只采用其明确的厂方回复及广告变更，不据此反推一条精确加速曲线。[Electrek 当年采访](https://electrek.co/2018/10/19/tesla-model-3-performance-advertised-0-60-mph-acceleration/)。

模拟器必须从同一次物理起步分别报告：

1. 严格静止：从驱动命令生效的物理步开始计时，公布初始速度和阈值插值。
2. 精确 1 ft rollout：位置前进 0.3048 m 时重新置计时原点，记录被排除的实测时间。
3. C/D 旧口径对照：首次达到 3 mph（1.34112 m/s）时计时；明确这是对旧方法的近似。

60 mph=96.56064 km/h；100 mph=160.9344 km/h。0–60 mph 与 0–100 km/h 必须分开；0–160 km/h 也不等于 0–100 mph。1/4 英里同时公布严格静止成绩、rollout 对照和距离、末速，不能偷偷扣一段固定时间。

## 2018 Track Mode 与外观边界

当年的 Performance Upgrade 包括 20 英寸 PS4S、升级制动、运动悬挂和碳纤维后扰流板。Track Mode 在年内经历原型、媒体体验和 OTA 上线，故不能把夏季体验、10 月加速测试、11 月发布版当成同一软件状态。[C/D 2018-09-07 原型体验](https://www.caranddriver.com/reviews/a23009022/2018-tesla-model-3-performance-track-mode/)。

11 月的发布版利用双电机和制动管理偏航、允许适度滑移、提高冷却与再生制动能力。其 1:21.49 圈速用了更宽 Cup 2 和不同刹车片，不能当成原配 PS4S 量产车的同条件成绩。[MotorTrend 2018-11-08 发布版实测](https://www.motortrend.com/features/tesla-model-3-performance-track-mode-release-version-review)。

本项目 Standard / Performance / Track 是方便模拟驾驶的控制预设；不得声称这是 2018 原车同名的三档动力菜单。Track 应改变扭矩分配与稳定干预，同时遵守相同综合功率和轮胎限制，不用额外功率作弊；不引入 Track Mode V2/V3、后来的自适应减振或 Highland 硬件。

模型外观是否含正确轮圈、红色卡钳、扰流板及运动悬挂，必须以实际 GLB 检查结论为准；车型物理配置为 Performance 不代表素材外观已完全相符。

## 可追踪的工程模型与验证约束

以下是建议，不是已执行的标定值。最终代码若取不同值，必须在物理报告中列出实际值和理由。

- 以 1,854 kg 为整备质量参考。另列乘员、载荷，避免把整备质量称为干质量；试跑可用 75 kg 驾驶员情景，但不能声称历史 C/D 测试负载已知。若额外建立轮胎刚体，要避免重复计入轮胎质量。
- 综合电机峰值约 335.6 kW、638.6 N·m；前后轴分别建立扭矩/转速曲线，共用综合功率限制。各轴的独立峰值、效率、齿比、高速弱磁衰减均为待标定工程参数。轮上力经减速比、效率和滚动半径换算，并受每轮摩擦圆、法向载荷、滑移和 TCS 约束。
- 理论外半径只用于初始几何检查。静载轮心、可视接地与有效滚动半径分别记录；可由行驶距离与车轮角度反算滚动半径，不用修改刚体速度消除误差。
- SOC、温度与电机效率只能建立透明的工程近似。未取得可用容量和完整热模型时，不将 80.5 kWh 全部当作保证可用电量。2018 再生制动不应不加说明地变成后来软件的完整自动停车体验。
- 质心、惯量、前后静态载荷、弹簧刚度/阻尼、轮胎负载敏感性、空气阻力及滚阻均须独立于 Roadster 定义；未找到可靠实测的数值一律标工程估算。

### 建议的标定目标与容差

以下容差是项目的工程验收范围，不是原始媒体的测量误差。冻结参数后再运行验证，不可按单项成绩更改计时器或直接写入速度。

| 测试 | 对照目标 | 建议初始容差 / 判定 |
| --- | --- | --- |
| 0–60 mph，C/D 旧口径对照 | 3.5 s | ±0.35 s；同时报告 strict rest 与 1 ft，历史 rollout 无法精确复原 |
| 0–100 mph，同口径 | 8.9 s | ±0.8 s；检查高速功率衰减，不仅调起步抓地 |
| 1/4 英里，同口径对照 | 12.1 s，114 mph | ±0.6 s、±5 mph；距离门槛与计时原点明确 |
| 最高速度 | 厂方 155 / 实测 153 mph | 保留两值；可用扭矩限速将稳态控制在 246–250 km/h，不能每帧硬设速度 |
| 0–100 km/h、0–160 km/h | 无本批历史同口径直接目标 | 完整实测报告；不能由 3.3 s 或 8.9 s 直接换标签 |
| 高速衰减 | 加速率随车速总体降低 | 记录 100–160 与 160–200 km/h 分段，核对轮上功率与阻力功率 |

每次测试记录代码提交、车辆 ID、模式、计时口径、物理步长、实际总质量、SOC、地面摩擦、坡度、初始刚体速度、逐轮角速度、驱动力/制动力、刚体速度和位置。优先同一平坦场地做正反向至少各 3 次；报告均值与离散程度。历史车况/天气未知时，测试结果是接近历史参考的工程模型，不是对真车精确复刻的证明。

## 未解决的资料缺口

没有取得 2018 Performance 的厂家独立电机完整曲线、效率地图、准确弱磁区、SOC/温度降额曲线、各桥完整传动规格、准确惯量/质心、悬架硬点、阻尼地图和轮胎魔术公式系数。未能从 Tesla 当前官网取得保持原版本的 2018 手册 PDF，已明确使用历史镜像并与官方后续资料交叉核验。Tesla 原 2018 Track Mode 博客当前访问失败，Track 特征以当年亲历媒体测试及官方 2018 投资者资料核对。以上缺口不能用新款 Performance 参数填补。
