# Roadster Flight Lab 0.9.9 · 坡道试验区

从车库选择车型，点「进入 FSD 城市」，选择导航目的地并启用 FSD。首次启动需要采集两秒驾驶历史并加载本地 Plan-R1 模型。WASD 或空格随时接管。「返回试车场」恢复场地驾驶和 Roadster 飞行。

从车库点「开始驾驶」，在底栏打开「坡道试验区」。四个分区共有二十条新坡道，选择车道后点「前往起点」。路牌和选单使用同一组编号。也可沿原特技跳台道路向前进入试验区。

在城市中打开 Tesla Garage 或按 Esc 可以选车。点「返回 FSD 城市」继续原来的城市行程，自动驾驶由你重新启用。点「开始驾驶」进入实体试车场。

蓝色轨迹从车头正中延伸，两侧各占半个车身宽。宽度随车型切换，按模型车身测量，不含后视镜。弯道沿连续样条绘制，两侧边缘按弯曲程度细分。沿路显示长度沿用 0.9.6 的短轨迹。积极模式会比较前车速度与当前巡航速度，检查邻道来车、信号灯和转弯前剩余距离。导航栏会显示部分跟车原因。

## 同向车道

FSD 会在转向前按车身宽度、车头与车尾的朝向检查预测路径。普通路段按同一行驶方向的道路边界判断；路口按导航指定的左转、右转或掉头曲线判断。积极模式采用模型预测的前进距离和停车节奏，沿已选车道、转弯连接线或变道曲线转向。蓝线直接显示跟踪路径，导出记录同时保留原始预测和执行轨迹。标准模式保留原始模型的横向决策及越界保护。车头已朝着逆行方向时，需要在本侧摆正后启用。停车脱困时，相邻车道正常会车无需倒车。

## 都会路网

城市道路中心线合计 61.43 公里。打开「运行状态与记录」→「试驾起点」，可以直接从「中城斜向大道」或「东港快速路」出发。斜向大道穿过长方形街区，北港和南环通过快速路接回老城区。原创路网的街区比例和斜向交叉口参考了[纽约市规划局中城街网图](https://www.nyc.gov/assets/planning/download/pdf/about/cpc/920260.pdf)。

## 地图导航

进入城市，点「地图选点」。点道路中间也能设终点，地图显示红色停车点、蓝色路线、主车及实时交通。点到建筑或绿地时，空心点标出原始落点，实心点标出最近能行车的位置，虚线显示两者距离。「定位」放大主车附近，可以继续缩放或拖动后再点。手动驾驶时点「开始导航」，FSD 已开启时新终点立即生效。

遇到持续拥堵时，导航会检查同一目的地的其他走法。遇到偏离车道或近距离无法前进时，独立的低速脱困控制器检查前后空间，可短距离倒车并重新汇入。周围都被挡住时会等车流腾出空间。红灯正常等待。蓝色模型预测在脱困控制期间暂时隐藏，HUD 会显示当前动作。

## 试驾

- 展开「运行状态与记录」，选择「东侧入口匝道」「环城高速」「环城隧道南口」或「滨河掉头区」，点「从此处出发」，再点「启用 FSD」。
- 默认「积极」在相邻车道前后留有空隙时尝试超越慢车，遇到中隔带在指定区域掉头。高速允许的导航巡航目标最高约 79 km/h。「标准」可对照原始模型的首选预测。
- 首次进入默认为 32 辆车。交通数量支持 10、12、20、32，后续会记住你的选择。修改数量后可重新启用 FSD。红灯依然需要排队。可以用「导出预测与驾驶记录」保存遇到的问题。
- 蓝线按车速显示未来八秒预测里的一段。画面将连续预测按车前距离对齐，同一时刻只画一条蓝线。模型选出的直行、转弯和变道都保留在驾驶记录里。积极模式用路线、速度及前车信息在每步模型评分最高的 96 个候选动作里选取一个。制动保护独立记录。城市道路为模拟器自建，FSD 为实验功能。
